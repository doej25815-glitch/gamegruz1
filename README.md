# gamegruz1
мямя
Clean starter scaffold for a new Base mini app project.

This repository keeps the same high-level structure as `basegame01`, but without
old game logic, contract addresses, or app-specific content.

## Stack

- Next.js App Router
- TypeScript
- Base + Farcaster related dependencies preinstalled for future development

## Project Structure

- `app/` - application routes and UI shell
- `lib/` - reusable domain and blockchain helpers
- `data/` - local static/project data
- `public/` - static assets

## Local Run

```bash
npm install
npm run dev
```
